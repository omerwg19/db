Supported lookups

Every identifier we can resolve

You do not choose a lookup type. Paste the identifier and Veriscope classifies it, then queries every source that has indexed it.

Email address

Breach appearances across corpora and stealer logs, linked accounts, and public profile footprint for the mailbox itself.

Phone number

Country and carrier resolution, line type, and accounts tied to the number across data brokers and app signups.

Username

Profile matches across social networks, forums, developer platforms, marketplaces and gaming services.

IP address

Geolocation, hosting provider, ASN and network owner, plus reputation and abuse-report signals.

Domain

WHOIS and registration data, DNS history, certificate transparency entries, and infrastructure change records.

Discord ID

Resolve an identifier to associated servers, roles, and publicly visible activity.

Full name

Multi-criteria search across name, location and employer to disambiguate between people with shared names.

Stealer logs

Credentials harvested by infostealer malware, grouped by infected machine so repeat targets and stale entries are visible.

Run one against your own accounts

The fastest way to judge the output is to point it at an address you already own.
